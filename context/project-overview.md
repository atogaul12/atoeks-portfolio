# Portfolio M. Ato'ulloh

## Ringkasan

Website portofolio pribadi dengan tema Sci-Fi / Space yang menampilkan profil,
pengalaman kerja, proyek, sertifikasi, dan kontak M. Ato'ulloh — seorang
Full-Stack Web Developer & Cybersecurity lulusan Teknik Informatika
Telkom University Purwokerto.

## Tujuan

1. Menampilkan profil profesional dan pencapaian secara visual menarik
2. Menyediakan akses mudah ke CV/resume dan kontak
3. Mendemonstrasikan kemampuan front-end (HTML, CSS, JavaScript vanilla)
4. Menjadi titik sentral untuk personal branding

## Alur Pengguna Utama

1. Pengguna membuka halaman → melihat Hero section dengan foto dan tagline
2. Scroll ke About → membaca bio, pencapaian, dan skill
3. Scroll ke Experience → melihat riwayat pekerjaan dan organisasi
4. Scroll ke Projects (Galleria) → melihat portofolio proyek
5. Scroll ke Certifications → melihat sertifikasi yang dimiliki
6. Scroll ke Contact → mengirim email atau mengunjungi sosial media

## Fitur

### Navigasi & Tampilan

- Navbar sticky dengan efek blur dan active highlight
- Starfield animation di background (kanvas JavaScript)
- Scroll reveal animation (Intersection Observer)
- Tema dark mode dengan aksen cyan/blue sci-fi

### Sections

- **Hero**: Nama, title, deskripsi singkat, CTA resume, tech tags, foto dengan orbit ring & HUD labels
- **About**: Bio detail, key achievements, skill categories (Web Dev, Cybersecurity, Tools, Soft Skills)
- **Experience**: Timeline pengalaman kerja dan organisasi
- **Galleria (Projects)**: Grid proyek dengan thumbnail, deskripsi, tech tags
- **Certifications**: Grid sertifikasi dengan issuer dan masa berlaku
- **Contact**: Email, social links (GitHub, LinkedIn, Telepon)

## Lingkup

### Dalam Lingkup

- Single-page website portofolio statis
- Animasi starfield, scroll reveal, active nav highlight
- Tema dark sci-fi dengan kustomisasi CSS variables
- Responsive layout (desktop & mobile)
- Integrasi foto profil, screenshot proyek, dan file CV

### Di Luar Lingkup

- Backend / server-side logic
- Database atau penyimpanan data dinamis
- CMS atau admin panel
- Form kontak dengan pengiriman email server-side
- Multi-language support

## Kriteria Sukses

1. Halaman dapat diakses dan responsif di desktop & mobile
2. Semua section menampilkan konten dengan benar
3. Animasi berjalan mulus tanpa jeda
4. Foto profil dan thumbnail proyek dapat diganti melalui file statis
5. Tombol resume mengarah ke file CV yang valid
